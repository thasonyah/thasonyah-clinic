## กติกาข้อมูลจริง

- ทะเบียนแยกจาก encounter; การติดตามต้องสร้าง encounter ใหม่และเชื่อมครั้งก่อน ไม่ทับผลเดิม
- ช่องไม่ทราบ/ไม่เกี่ยวข้องต่างจากไม่พบโรค; ไม่ตั้งผลปกติหรือความยินยอมให้อัตโนมัติ
- จักรราศีไม่ต้องถามคนไข้: ใช้วันเกิดในทะเบียนและกฎที่ผู้เชี่ยวชาญตรวจรับเท่านั้น ต้องรองรับข้อมูลไม่ครบและบันทึกรุ่นการคำนวณ
- ชื่อผู้ฝึกงาน/ชั้นปีบนหัวกระดาษ B แยกจากชื่อคนไข้ (การตีความจากรูปแบบเอกสาร)
- ต้นฉบับพิมพ์ชื่อธาตุแตกต่างกันบางตำแหน่ง คลังคำจริงต้องเก็บชื่อมาตรฐาน ชื่อจากต้นฉบับ และแหล่งหน้า พร้อมผู้ตรวจรับ
- ตัวเลือกสถานะรูปธาตุเป็นการออกแบบช่องกรอกเพิ่มเติม ไม่ใช่ข้อสรุปว่าต้นฉบับกำหนดทุกตัวเลือกไว้
- ความยินยอมจริงใช้ข้อความของคลินิกที่ตรวจรับแล้ว ไม่ยกข้อความยกเว้นความรับผิดจากตัวอย่างมาใช้โดยอัตโนมัติ
- การลงนามต้องมีผู้รักษาที่มีสิทธิ์, audit log, รุ่นบันทึก; ต้นแบบไม่ใช่การยินยอมหรือการสั่งยาจริง

## ขอบเขตที่เสร็จในรอบนี้

เพิ่มหมวดใน /design/treatment ทุกหมวดเปิด–ปิดได้ ค่าคงอยู่ระหว่างสลับสามแท็บขณะที่หน้านี้ยังเปิดอยู่ ข้อมูลเป็น React state เท่านั้น ออกจากหน้า/รีโหลดจะหาย ไม่ใช่เวชระเบียนถาวร

## ยังต้องทำในขั้นฟังก์ชันจริง

แบบข้อมูลและ migration/API, validation, สิทธิ์/การลงนาม, การบันทึกจริงและ audit, ผังร่างกาย, BMI/อายุ, กฎจันทรคติ/จักรราศี, คลังคำตรวจรับ, การจ่ายยา, OPD PDF และการติดตามแบบหลาย encounter พร้อมทดสอบครบเส้นทาง
