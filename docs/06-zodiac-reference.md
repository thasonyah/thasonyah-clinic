## การนำไปใช้

- คนไข้แจ้งวันเกิดตามทะเบียนตามปกติ ไม่ต้องถามว่าราศีอะไร
- เมื่อได้ราศีจากกฎที่ตรวจรับแล้ว จึง lookup ธาตุ ภาวะ และระคนจากตารางนี้
- เก็บแยกจากคำวินิจฉัยของแพทย์: ภาวะในตารางเป็นข้อมูลตามตำรา ไม่ใช่ผลตรวจว่าคนไข้มีธาตุกำเริบ หย่อน หรือพิการจริง
- เก็บ source reference, rule version, input DOB, lunar conversion version, computed_at และสถานะคำนวณร่วมกับผล
- เปลี่ยนวันเกิดต้องคำนวณใหม่แบบมีประวัติ; encounter ที่ลงนามแล้วต้องรักษา snapshot เดิม

## ส่วนที่ภาพนี้ยังไม่กำหนดชัดพอสำหรับคำนวณ

ภาพมีตัวเลขเดือนจันทรคติและสัญลักษณ์ ข/ร รอบเส้นแบ่ง แต่ไม่มีคำอธิบายครบถึงวันที่เริ่ม/สิ้นสุด การนับวัน เวลาเปลี่ยนวัน และเดือนพิเศษ จึงยังห้ามสมมติใช้ช่วงวันที่ของราศีตะวันตกแทน

ต้องตรวจรับ:
- ความหมาย ข/ร และขอบเขตวันขึ้น/แรมที่ใช้เปลี่ยนราศี (เทียบภาพก่อนหน้าและตำรา)
- เดือน 8 สองหน / อธิกมาส และอธิกวาร
- วิธีแปลงวันเกิดสุริยคติเป็นจันทรคติ พร้อมช่วงปีที่รองรับและกรณีขอบเขต
- ตัวอย่างวันเกิดที่ทราบผลถูกต้อง ครอบคลุมก่อน/หลังจุดเปลี่ยนราศี

สถานะ: บันทึก mapping อ้างอิงแล้ว; ยังไม่เปิดคำนวณจากวันเกิดในแอป
